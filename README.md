# guess-anime-legal

《猜动漫角色》TapTap 上架用 **公开** 隐私政策与用户协议页（GitHub Pages）。

## 开启 Pages

1. 仓库须为 **Public**。
2. GitHub → **Settings** → **Pages**
3. **Build and deployment** → Source: **Deploy from a branch**
4. Branch: **main**，Folder: **/docs** → Save
5. 约 1～3 分钟后访问：

- 隐私政策：`https://itsoldierone.github.io/guess-anime-legal/privacy.html`
- 用户协议：`https://itsoldierone.github.io/guess-anime-legal/agreement.html`

TapTap 控制台填上列 HTTPS 地址；须用手机流量或无痕浏览器能直接打开全文。
